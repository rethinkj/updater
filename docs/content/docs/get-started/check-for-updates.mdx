This page builds an app that checks the releases of the GitHub CLI for a version newer than the one it runs, prints what changed since, and downloads the new version's archive for Linux x64, verified against its SHA-256 checksum. The whole app is [`CheckForUpdate`](https://github.com/rethinkj/updater/blob/main/examples/src/test/java/com/rethinkj/updater/examples/docs/CheckForUpdate.java) in the repository's examples; its `main` runs it against GitHub.

## Show the release notes

`update.releases()` holds every release newer than the installed one, newest first, so an app that skipped versions shows everything that changed since. The notes are Markdown, for the app to show the way it wants; the library prints nothing.

## Download and verify

`latest()` is the release to update to. `asset` picks its file for this platform by a pattern for the whole name, and `Downloader` loads it into a new file in `folder` and returns it, with its checksum, only if it matches. The last argument is told how many bytes have arrived, for a progress bar. See [Verification](/docs/concepts/verification) for where the checksum comes from and how to cancel.

```java snippet="download"
```

The file is the app's to delete once it is no longer needed. To install it, the app hands the download to the helper; see [Applying updates](/docs/concepts/applying-updates).
