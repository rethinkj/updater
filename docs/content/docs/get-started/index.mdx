---
title: Installation
description: How to add rethinkj Updater to a Maven project.
---

rethinkj Updater needs JDK 25 and runs on Windows 11 and later and on Linux, both on x64. Nothing is implemented yet and no artifact is published, so for now the only way to depend on it is to build it yourself.

## Build it

With JDK 25 and Maven 3.9 or later:

```sh
git clone https://github.com/rethinkj/updater.git
cd updater
mvn install
```

This puts the artifacts in your local Maven repository (`~/.m2`).

## Depend on it

```xml title="pom.xml"
<dependency>
  <groupId>com.rethinkj.updater</groupId>
  <artifactId>rethinkj-updater-core</artifactId>
  <version>0.1.0-SNAPSHOT</version>
</dependency>
```

`rethinkj-updater-helper` is the separate process that applies an update. How an app ships it alongside itself is not decided yet; see [Applying updates](/docs/concepts/applying-updates).
