---
title: Sources
description: Where the library looks for new versions of an app.
---

A source answers one question: which versions of the app exist, and where are their files? `Source.releases()` lists them as `Release` objects: the version, tag, title, publication date, release notes as Markdown, whether it is a pre-release, and the attached files as `Asset` objects with name, address, size and, where the source reports one, a SHA-256 checksum.

A source reports what exists. Deciding which version is newer and whether to offer it is the library's job, not the source's. Versions are compared by SemVer, pre-releases included (`Version`). Releases whose tag is not a SemVer version, such as `nightly`, and drafts are left out.

```java snippet="source"
```

Another constructor takes the API's address, for GitHub Enterprise Server, and a token. The address must be https, or on this machine: over plain http anyone on the way could change which files a release lists and their checksums. It reads every page of releases, 100 to a request. Where GitHub reports a file's SHA-256 checksum, the `Asset` carries it; where it reports none, `sha256()` is empty and the file cannot be verified this way.

Without a token GitHub allows 60 requests an hour per IP address. A token raises the limit and lets the releases of a private repository be read. With a token, each `Asset`'s address is in the API, and `new Downloader(source)` downloads it with the token. When the limit is used up, `releases()` throws a `RateLimitException`, whose `retryAt()` says when GitHub accepts requests again. Any other failure is an `IOException` with a message that says what went wrong; nothing is printed.

## Gitea and Forgejo

```java snippet="gitea-source"
```

Forgejo, a fork of Gitea, has the same API, and both answer as GitHub's does, so the same rules hold as for `GitHubSource`: https or this machine only, and every page read, 50 releases to a request. Neither reports a file's SHA-256 checksum, so a release needs a checksum file (see [Verification](/docs/concepts/verification)). A token lets the releases of a private repository be read, and `new Downloader(source)` downloads its files with the token, which goes only to the instance, never to where the instance redirects.
