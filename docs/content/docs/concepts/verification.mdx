---
title: Verification
description: How a download is checked before it is used.
---

Not implemented yet. This page describes the intended design.

Every download goes into a temporary file first. It is checked against a SHA-256 checksum that the release publishes, and only a file that matches is used. If the app configures an Ed25519 public key, the download must also carry a valid signature made with the matching private key; without one it is rejected.

The checksum protects against broken downloads. The signature protects against a release that someone other than the app's authors published, for instance through a stolen account token.
