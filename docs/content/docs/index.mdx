rethinkj Updater is a Java 25 library that keeps a desktop app up to date on Windows and Linux. It finds new releases, reads their release notes, downloads and verifies them, and replaces the app's files once the app has exited.

**Status: early.** Little is implemented yet: versions, reading GitHub releases, finding the update, downloading it with SHA-256 verification, and the helper that replaces the app's files once it has exited, starts the new version and puts the old one back if the new one does not confirm that it runs. The version is `0.1.0-SNAPSHOT`, published as SNAPSHOTs from every push to `main`. The pages under [Concepts](/docs/concepts) describe what is built and name what is not yet.

## What it is meant to do

It is headless: it shows nothing itself, and hands the app objects (versions, release notes, progress, results) to show the way the app wants.

- **Find updates** on GitHub Releases, GitLab, Gitea or Forgejo, or in a JSON manifest on any web server. Versions are compared by SemVer, with a stable channel and pre-release channels such as beta or nightly.
- **Read release notes**: the notes of every version between the installed one and the new one, as Markdown, split into sections such as Added, Fixed and Breaking.
- **Download and verify**: check each download against a SHA-256 checksum and, if the app configures a public key, an Ed25519 signature.
- **Apply** an archive (zip or tar.gz), a single JAR, or a native installer. A small helper process waits for the app to exit, replaces its files, restores them if anything fails, and starts the app again.

## Modules

| Artifact | What it is |
| --- | --- |
| `rethinkj-updater-core` | Sources, versions, release notes, download and verification |
| `rethinkj-updater-helper` | The process that replaces the app's files and starts it again |

Both share the group `com.rethinkj.updater`.
