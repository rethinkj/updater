- `rethinkj-updater-helper` applies a tar.gz that holds symbolic links, as long as each leads to a file or folder in the app's folder. A jpackage or jlink image on Linux links the legal notices of its runtime this way, so the helper rejected such an image packed with a plain `tar czf`. Any other link is still rejected, and so is an update that would carry a user's file over through a link, as when the new version makes the folder that holds it a link.
