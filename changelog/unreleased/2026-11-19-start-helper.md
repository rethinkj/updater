- `Installation` starts the helper from the app: `replaceOnExit(download)` and `restart(download)` write the plan and start the helper JAR found on the class path, on a copy of the app's runtime if that lies in the app's folder, so that the helper outlives the app and, on Linux, its terminal. `writable()` tells beforehand whether the user may replace the app, and `result()` reports the last update once and deletes what updates left behind. `Installation.launcher(updates)` reads the app's folder and start command from a jpackage launcher. The helper does not start the app again yet.
