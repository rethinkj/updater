- If the helper is ended before it reports, as when the user logs off while it waits for the new version to confirm, or shuts down while it waits after `replaceOnExit`, `Installation.result()` now reports in its place at the next start instead of nothing until the next update: `APPLIED` if the new version is in place, whose backup `<app>.backup-<n>` it then deletes, else `REJECTED` with the reason `failed`. For this the helper names the backup in a new file `backup.properties` in the update folder, and a helper that cannot lock `helper.lock` now changes nothing and reports `failed`.
