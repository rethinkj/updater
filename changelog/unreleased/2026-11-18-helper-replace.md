- `rethinkj-updater-helper` replaces the app once it has exited, from a zip, a tar.gz or a single JAR: it checks the download's SHA-256 again, builds the new version beside the app and swaps the two with two renames, which it undoes if the second fails, and tries again for 30 seconds while a file is locked. Files that `rethinkj-updater.files` in the app's folder does not name are carried over; `java -jar rethinkj-updater-helper.jar list <folder>` writes that list. It does not start the app again yet.
