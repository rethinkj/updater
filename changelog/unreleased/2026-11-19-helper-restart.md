- `restart(download)` now starts the new version: the helper waits up to two minutes for `Installation.confirm()` from it, and if none comes, or the new version exits first, it ends the new version with every process it started, puts the old version back and starts that, with the result `rolled-back` and the reason `not-confirmed`. With `restart`, the helper also starts the old version after a `rejected` result, and it deletes the old version only once the new one has confirmed.
