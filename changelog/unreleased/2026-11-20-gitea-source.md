- Added `GiteaSource`, which reads the releases of a repository on a Gitea or Forgejo instance, such as Codeberg, as `GitHubSource` does on GitHub: every page, with pre-releases, release notes and files, over https or from this machine only. Neither reports checksums, so a file is verified with a checksum file of its release. With a token it reads a private repository, and `new Downloader(source)` downloads its files, sending the token only to the instance, never to where the instance redirects.
